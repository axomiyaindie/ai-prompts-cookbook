# Contributing

Thanks for your interest. To keep this cookbook useful, every contribution must follow a consistent format.

## Rules
1. Use the template in templates/prompt-template.md.
2. Include a tested example input and a "Why It Works" section.
3. Place the file in the correct category folder under prompts/.
4. Use clear file names (lowercase, hyphens, .md extension).
5. Do not include secrets, API keys, or personal data.
6. Do not copy paid or copyrighted prompt collections.

## Steps
1. Fork the repo.
2. Add your file following the template.
3. Commit with a clear message.
4. Open a Pull Request describing what the prompt does and which platform it was tested on.
