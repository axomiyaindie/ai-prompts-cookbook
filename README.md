# AI Prompts Cookbook

A curated collection of battle-tested prompt recipes for AI tools, organized by platform and use case.

## What is Inside
Unlike random prompt dumps, every recipe here follows a consistent template. It includes the prompt, an example, and a note on why it works.

## Structure
- prompts/ - Ready-to-use prompts by category (Coding, Writing, Data, Image).
- patterns/ - Reusable techniques (like Role + Constraint + Format).
- templates/ - The blank recipe template used for contributions.

## How to Use
1. Browse to the relevant category.
2. Copy the prompt.
3. Replace the {{PLACEHOLDERS}} with your own content.
4. Paste into your AI tool (ChatGPT, Claude, Cursor, Midjourney, etc.).

## Contributing
Please follow the format in templates/prompt-template.md. Prompts should be tested and include a "Why It Works" section.
